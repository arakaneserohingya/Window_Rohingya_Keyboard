Hanifi Rohingya Windows

Extract the native Windows package and run Install.cmd. After signing out and back in, press Win+Space and select Hanifi Rohingya. Choose Noto Sans Hanifi Rohingya as the document font and right-to-left paragraph direction.

The normal layer follows the SIL Hanifi Rohingya layout. Open preview.html in the repository to see all key positions.

  • V: vowel A.
  • Shift+H: Harbahay. Shift+T: Tahala. Shift+A: Tana.
  • Backquote or Shift+Space: Sakin. Backslash: Na Khonna.
  • Shift+Backquote: Tassi.
  • Shift+comma/period/slash: comma/full stop/question mark. Shift+L: semicolon.
  • Numbers: Rohingya digits. Shift+number: US punctuation.

Unused shifted letters produce no text, following the SIL layout. Type in logical reading order; do not reverse the text. Combining signs follow the letters/vowels they modify.
